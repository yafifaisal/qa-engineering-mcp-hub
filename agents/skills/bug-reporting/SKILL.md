# Bug reporting

This repository skill is scaffolded for Future Milestone 10. It may prepare a
local draft from user-supplied evidence, but it must not create or update Jira,
Xray, TestRail, or another external system in Milestone 00.

Include reproducible steps, expected and actual results, affected revision and
environment, deterministic failures, redacted evidence references, and known
limitations. Do not expose credentials or PII. External publication requires a
preview, explicit user approval, and an idempotency strategy.
